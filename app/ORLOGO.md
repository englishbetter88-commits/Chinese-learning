## Зар хэрхэн ажиллах вэ
Зар **хэзээ ч өөрөө гарч ирэхгүй**. Хичээлийн дунд, эхэнд ч гарахгүй, зөвхөн хэрэглэгч сонгож дарвал гарна:
- **Зүрх дуусахад:** «Зар үзээд 1 зүрх авах», өдөрт 3 удаа.
- **Өдрийн бэлгээ авсны дараа:** «Зар үзээд нэмэлт бэлэг авах», өдөрт 1 удаа.
- **Өндөг дарж байх үед:** «Зар үзээд өндгийг хурдасгах (+50 XP)», өдөрт 2 удаа.
- Нийтдээ өдөрт 6 зар хүртэл үзнэ. **Pro хэрэглэгчид зар огт харахгүй.** Энэ нь Pro авах бас нэг шалтгаан болно.
- Зарыг дуустал нь үзсэн тохиолдолд л шагнал өгнө.

Ийм зар хэрэглэгчийг залхаахгүй, Duolingo ч ийм зар ашигладаг.

## AdMob тохиргоо · 15 мин
1. https://admob.google.com → Google бүртгэлээрээ орно. Монголоос бүртгүүлэх боломжтой.
2. **Apps → Add app** → Android → «Ханз эхлэл». Апп Play Store-д гарсны дараа холбоно.
   - **App ID** авна (`ca-app-pub-…~…`).
3. **Ad units → Rewarded** → нэр `rewarded_main` → **Ad unit ID** авна (`ca-app-pub-…/…`).
4. iPhone-д мөн адил хийнэ (Apple бүртгэл нээгдсэний дараа).
5. **Payments:** хаяг, банкны данс оруулна. Google орлогыг сар бүр USD-ээр шилжүүлнэ, доод хэмжээ $100.
6. GitHub → репо → **Settings → Secrets and variables → Actions → Variables** таб → **New repository variable**:

| Нэр | Утга |
|---|---|
| `ADMOB_APP_ID_ANDROID` | Android App ID (`…~…`) |
| `ADMOB_REWARDED_ANDROID` | Android rewarded ad unit ID (`…/…`) |
| `ADMOB_APP_ID_IOS` | iOS App ID |
| `ADMOB_REWARDED_IOS` | iOS rewarded ad unit ID |

Эдгээр нь нууц биш учраас **Secrets биш, Variables** хэсэгт оруулна. Оруулаагүй үед апп Google-ийн **туршилтын зарыг** харуулна. Туршилтын зар ажилладаг ч мөнгө олохгүй тул туршихад тохиромжтой.

> ⚠️ Өөрийнхөө аппын жинхэнэ зарыг хэзээ ч өөрөө дарж болохгүй. Google үүнийг хуурамч гэж үзээд AdMob бүртгэлийг хаадаг. Туршихдаа зөвхөн туршилтын зар ашиглаарай.
